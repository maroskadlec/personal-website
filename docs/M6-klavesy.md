# Mapa kláves (jedna stránka)

Všechno, co jde myší, jde i klávesnicí, kromě přesouvání a zvětšování oken tahem (obsah to nepotřebuje, okno jde zvětšit tlačítkem zoom). ⌘ je na Windows a Linuxu Ctrl. Stav k 2026-10-14, ověřeno skutečnými klávesami v Chromiu.

## Start

| Kde | Klávesa | Co udělá |
|---|---|---|
| Brána | Enter nebo Mezerník (když nic nemá fokus) | zapne počítač |
| Brána | Tab | tlačítko zapnutí → Sound → Plain text version |
| Boot manager | ↑ ↓ | vybere položku |
| Boot manager | Enter nebo Mezerník | spustí vybranou |
| Boot manager | 1 nebo O · 2 nebo T | spustí Marian OS · spustí Terminal |
| Boot manager | jakákoli jiná klávesa | zastaví odpočet (čtečka to oznámí) |
| Úvodní obrazovka | Esc, Enter, Mezerník | přeskočí čekání |

## Všude, když počítač běží

| Klávesa | Co udělá |
|---|---|
| `` ` `` (zpětný apostrof) | přepne Desktop a Terminal (ne při psaní do pole) |
| Tab / Shift+Tab | menu bar (hruška) → přepínač Desktop \| Terminal → zvuk → ikony |
| ← → Home End na přepínači | přesune se mezi „Desktop" a „Terminal"; Enter nebo Mezerník přepne |

| | Home / End | první / poslední |

| | F2 | přejmenuje (Enter potvrdí, Esc zruší) |
| | Delete nebo Backspace | do Koše |
| | ⌘A | vybere vše |

## Terminal

| Kde | Klávesa | Co udělá |
|---|---|---|
| Stránka | psaní | kdekoli se začne psát do příkazové řádky dole |
| Stránka | Tab | odkazy v obsahu → příkazová řádka (dock) |
| Dock | Enter | spustí příkaz |
| Dock | ↑ ↓ | historie příkazů |
| Dock | Tab | dokončí příkaz nebo jméno; druhý Tab vypíše možnosti |
| Dock | Esc | zavře výpis |
| Úvodní „build" | Enter, Esc nebo tlačítko skip | přeskočí |

## Nejde klávesnicí (a nemusí)

- Přesun a změna velikosti oken a přetahování ikon. Totéž umí menu a tlačítka (Clean Up Desktop, Move to Trash, Put Away, zoom okna).
- Titulky (sedmkrát rychle kliknout na hrušku v About This Computer): skrytý vtípek, jen myší nebo dotykem.

## Jde jen klávesnicí

- Konami kód (skrytý): odemkne „Do Not Open". Bez klávesnice totéž udělá pětkrát rychle klepnout (nebo kliknout) na hodiny v menu baru.
